# Wireframes

Page wireframes (image files) that pages are built from.

- Name each file after its task: `HN-XXX-short-slug.<png|jpg>`,
  e.g. `wireframes/HN-005-engagement-overview.png`.
- Reference it in the task file's `wireframe:` frontmatter field.
- Build pages from them with the `wireframe-to-page` skill.
- Wireframes must not contain real participant data.
